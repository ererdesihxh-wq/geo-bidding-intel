# GEO 招投标情报站

GEO（生成式引擎优化 / Generative Engine Optimization）领域招标、投标、中标情报实时追踪。

## 这是什么？

从2025年开始，GEO（Generative Engine Optimization，生成式引擎优化）从企业营销的"可选项"变成了"必选项"。九号公司、华润集团、东风本田、东鹏控股、宁波地方政府、五粮液、美团、知乎等大量企业和政府机构已启动GEO项目的公开招标。

**当前收录：31 个项目，覆盖 23 个行业，涉及已知预算总额超 2000 万元。**

这个工具收集整理GEO领域的所有招投标信息，帮助行业从业者：

- **了解市场格局**：哪些行业/企业在采购GEO服务
- **把握价格区间**：GEO项目的预算范围
- **发现商机**：正在招标的项目
- **分析竞争**：哪些公司中标了哪些项目

## 项目结构

```
GEO招标情报/
├── README.md
├── data/
│   └── bidding_data.json       # 主数据文件
├── docs/
│   ├── index.html              # 可视化看板（支持本地打开）
│   └── bidding_data.json       # 同步的数据文件
└── scripts/
    ├── build_data.py           # 数据集构建脚本（完整数据在此）
    ├── generate_html.py        # 从JSON生成内嵌数据的HTML
    └── update_bidding.py       # 命令行更新工具
```

## 使用方式

### 查看数据概览
```bash
python scripts/update_bidding.py
```

### 添加新项目
```bash
python scripts/update_bidding.py --add
```

### 批量导入CSV
```bash
python scripts/update_bidding.py --batch projects.csv
```

CSV格式：`company,industry,title,status,budget,bid_deadline,publish_date,summary,winner,source_url`

### 更新数据后同步到docs
```bash
python scripts/build_data.py           # 从源码构建JSON
python scripts/generate_html.py        # 更新HTML内嵌数据
```

## 更新频率

- 建议每周检查一次招标平台，补充新项目
- 每次更新后运行 `build_data.py` + `generate_html.py`
